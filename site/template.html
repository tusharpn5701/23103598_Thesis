Rules of the penalty box

Every shot is one decision. The attacker sees where it stands and picks an aim point on the goal. The keeper sees a noisy read of the shot and picks where to dive. Physics decides the rest. These are the same rules the agents trained under.

Inside the networks

Aim map

Each small goal is a shooting spot in the box. The dot shows where the attacker's network aims from that spot. The shading behind it is the scoring rate from that spot against the chosen keeper, simulated in your browser.

Code

The v2 folder is a cleaned-up, runnable version of the thesis code. The original files are kept unchanged for reference. Everything on this page comes from v2/: train the agents, evaluate them, then export the weights the simulator uses.

pip install -r v2/requirements.txt cd v2 python train.py # trains all four agents (about 10 minutes on a laptop CPU) python evaluate.py # head-to-head matrix, figures/ and results/results.json python export_web.py # weights + curves for this page

What changed in v2

Penalty Lab accompanies the MSc thesis "A Comparative Analysis of Reinforcement Learning Approaches for Attacker and Goalkeeper Agents in Simulated Soccer", School of Computer Science, University of Galway, 2024.

Simulator, aim map and per-spot rates run in the browser with the exported network weights. Tables and curves come from v2/evaluate.py and v2/train.py.
